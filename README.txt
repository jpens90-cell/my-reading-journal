Between the Pages V4

Upload the CONTENTS of this folder to the ROOT of your existing GitHub Pages repository. Keep the same site URL.

Before updating, export a JSON backup from V3. Your existing library uses the same localStorage key, modernBookJournalV1.

New: six appearance themes, automatic dark appearance, quick page updates, series tracking, reviews, Open Library catalogue suggestions.

After deploying, open the hosted site in Safari and reload. If an installed Home Screen app still shows V3, allow it to refresh online.

Personal reading data stays on-device. Book searches and recommendations require internet access.

V5 - Share My Reading
Open Library > Share my reading > Select books to share. Choose individual books (currently reading selected by default), optionally include progress, then tap Preview / Save as PDF. The browser's print-to-PDF feature runs on your device; no accounts or paid services. On iPhone use the print preview Share button to save/send the PDF. Book covers may require internet access to display in the PDF.

Update GitHub Pages: upload all V5 files to repository root, replacing existing files, then wait for Pages deployment. Your saved book data remains in this browser's localStorage when you use the same site URL and browser. Back up your journal before updating.

V5 UPDATE: READING REFLECTIONS
- Open any book in your Library and scroll to Reading reflections.
- Add optional chapter/page and title, then write your reflection.
- Edit/delete entries; spoiler flag available. Entries are saved locally with each book and included in JSON backups.
- Share My Reading > Include reading reflections is OFF by default. Only enable it if you want your selected books' entries printed in the PDF.
- OceanofPDF links have been removed.
